宽图与手势

页面单元生成对齐原作 ReaderViewItemGenerator：页面宽高取自 Komga 的 Media.pages[].dimensions，height > width 为竖版，否则为 宽图（跨页）。宽图在「拆分宽页」开启时整幅展示（可横向平移）或切成前后半分别翻页；双页模式下宽图不与邻居配对，独占一个 spread；封面页与末页永远单页。
手势对齐原作 DIVINA 的 UIKit 手势栈：横向滑动翻页（Compose HorizontalPager 内置拖动 + 速度 fling + snap）、点按左/右三分之一翻页、点按中间呼出/收起 chrome、双击在 1× / 2.2× 间切换、双指捏合连续缩放（放大后单指平移，翻页手势让位）。竖排 / 条漫模式切换为纵向 pager。

与 iOS 版的差异清单（有意裁剪）

  • 面板分镜模式（Panel Mode，DivinaPanelModeView + CoreML 分镜检测）：本版不实现，按用户要求只做记录。
  • 超分辨率（waifu2x .mlmodel 端侧超分）：不实现；Android 侧无现成等价物，后续可评估 ONNX Runtime。
  • 漫画翻译（Vision OCR + 翻译覆盖层）：不实现；后续可评估 ML Kit 文本识别。
  • EPUB 的 CoreText 排版引擎：不做双引擎；EPUB 统一走 WebView + ReadiumCSS（Android WebView）。
  • 阅读器页转场样式「仿真卷页」：设计稿列出选项，实现优先级低（覆盖/滚动先行）。
  • 阅读中底部 accessory bar（iOS 26 特性）：无 Android 对应，不移植。
  • komf / Tracker 仅管理员或服务器支持时可见：与原作能力门控一致（ServerProfile.supports(.komf) / tracker 库开关），非功能缺失。
  • 离线模式（OfflineView 的断网浏览态 / 离线横幅 / 离线失败回退）：本版不做，按用户要求只做记录；下载与下载管理（队列 / 策略 / 已下载清理）保留，见「下载」与「下载管理」分节。
  • 其余全部按原作结构 1:1：仪表盘五分区、浏览 chip 流筛选、详情 Hero/操作卡/Tracker chips、列表三条带、库范围菜单挂点、三档布局切换。
